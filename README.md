# 店じまいの合図 — 境界の手前

高瀬航（32・整体師兼パーソナルトレーナー）と小野寺由衣（29・会社員）の、最終枠が二夜続くノベルです。ビルドは要りません。

遊べる場所は [https://otomelab.github.io/takase-novel-long/](https://otomelab.github.io/takase-novel-long/) です。手元では `index.html` をブラウザで開いても同じゲームが動きます。

## 人物

高瀬航が指導し、施術します。由衣は受ける側です。由衣は首、肩、肩甲骨まわりが慢性的に凝っていて、初回カルテは肩甲骨挙上・巻き肩です。同年代の女性と比べられたくないので、男性の高瀬を選んでいます。

規則はひとつです。客が自分の足で越えてくるまで、高瀬からは動きません。

## 遊び方

クリック、または Enter / Space で文章を進めます。選択肢は由衣の行動です。

- 左上の **理性** は高瀬の自制です。0 から 100 です。
- 右上の **BPM** は由衣の脈です。
- ♥ で公式カルテと、高瀬の裏メモ（裏カルテ）が開きます。数値も、メモの文面も、その場の状態で変わります。裏メモは最初から高瀬の素の口調で、表の丁寧語がどこまで持ったかも書きます。

BGM は低いうなりと、脈に合わせた心音です。オートは文章を自動で送ります。

## 理性と口調

高瀬の台詞は、理性の高さで同じ意味のまま四段階に崩れます。名前つきの筋肉と動脈（大円筋、小胸筋、橈骨動脈）は、崩れたあとも触る理由として残ります。

| 理性 | 口調 | 聞こえ方 |
| --- | --- | --- |
| 80以上 | 丁寧語 | 「橈骨動脈、ここで触れます。10秒だけ数えますね」 |
| 64–79 | 欠け | 「橈骨動脈、ここです。……10秒だけ」 |
| 46–63 | 混線 | 「俺、数えるんで」と漏れて、です、に戻そうとする |
| 45以下 | タメ口 | 「10秒も要らないだろ」 |

理性が 62 未満のまま小胸筋の施術に入ると、吐息と半秒だけ熱が漏れます。高瀬は自分で手を戻し、「今のは、施術じゃない」と認めます。由衣が「やめてください」と言えば、その語尾と同時に手は離れます。

## 脈が120を超えると

高瀬が由衣の橈骨動脈を測ったあと、**BPM が 120 以上のときだけ**「彼の左手首を取る。親指を、橈骨動脈に当てる」が出ます。120 未満の夜には、この選択肢自体がありません。

返したあとでベッドに残ると「寸前」に近づきます。返したまま帰ると「空いた枠」になります。

## 三つの終わり

**店じまいの笑顔**

名前のついた筋肉だけで終えて、また来ると別れる夜です。鍛えに来て、手首を預け、ベッドで力を抜くと、ここへ着きます。理性は比較的残ります。「触れてほしい」と言っても理性が 58 より上なら、聞こえたまま越えない別の顔もあります。

**寸前**

由衣が自分から越えて、高瀬の理性が持たず、唇の直前で照明が落ちる夜です。預けたい、と手首を預け、脈を返し、ベッドで力を抜くと、ここへ着きます。脈を返さなくても、「触れてほしい」と言ってベッドで力を抜き、理性が 58 以下なら同じ終わりです。それより先は書きません。

**空いた枠**

翌週の最終枠が空いたままになる夜です。鍛えに来て、手首を抜き、「今日は大丈夫」と帰ると、高瀬は最後まで丁寧語のまま、礼だけが深くなります。熱が先に漏れたあとで「やめてください」と言った夜も、脈を返したのにベッドへ入らず帰った夜も、ここです。高瀬は追いません。

## 2回目

1回目の終わりは `localStorage`（`slot016.night1`）に残ります。終わりのカードの「2回目へ」で、その夜の続きが開きます。タイトルの三つのボタンは、続きを試すためのもので、押すと保存もその終わりに置き換わります。

入り方は、前回の終わりで変わります。肩甲骨、小胸筋、大円筋は同じ名前のまま、意味だけが違います。口調の四段階、BPM 120 以上の脈返し、裏カルテ、拒まれたらその語尾で手が離れること、暗転は由衣が越えたあとだけ、は1回目と同じです。

**店じまいの笑顔のあと**は、信頼して戻ってくる夜です。高瀬は温かいけれど、自分からは越えません。

> いらっしゃい、由衣さん。肩甲骨、前回より下がったままです。大円筋も、いい位置です。大円筋からいきますか。それとも肩甲骨だけ、甘やかしますか

終わりは「いつもの最終枠」「名前を越えて」「今日はここまで」です。

**寸前のあと**は、高瀬が丁寧語を厚くしすぎる夜です。前回の暗がりは、どちらも口にしません。

> いらっしゃいませ。小野寺様。本日は肩甲骨挙上の確認のみ、実施させていただきます。小胸筋より先には触れません。どこまで見るかは……由衣さん
>
> 一拍、店の中が黙る。高瀬は自分の舌に気づき、息を一度だけ飲み直す。
>
> ……失礼しました。小野寺様。範囲は、小野寺様がお決めになります

裏カルテには、小野寺様が由衣さんまで落ちて、一拍で戻したことだけが残ります。

終わりは「丁寧な距離」「敬語が折れる」「言わないまま」です。

**空いた枠のあと**は、由衣が三週空けて自分で予約を入れ直す夜です。高瀬は丁寧なまま追いかけず、身体の変化だけを見ます。

> いらっしゃい。ご無沙汰しています。肩甲骨、見ますか

聞いたあとは、返事を待つだけです。もう一度は聞きません。

終わりは「空いた週のあと」「自分の足で」「また空く枠」です。

## 経路の確認

```
node js/simulate.js
```

1回目は全 60 経路で、店じまいの笑顔 21、寸前 13、空いた枠 26 です。2回目は前回の終わりごとに、いつもの終わり・暗転・来なくなる夜へ分かれます。店じまいの笑顔のあとは 60 経路（31 / 13 / 16）、寸前のあとは 70 経路（40 / 14 / 16）、空いた枠のあとは 50 経路（12 / 8 / 30）です。括弧の順は、名前の内側で終わる夜、暗転、扉まで出ない夜です。

## 長編版で足した場面（1回目の夜）

元の `takase-novel` を `takase-ep0/novel-long/` にコピーして、1回目の夜を長くしたものです。終わりは同じ3つのままです。

| 場面 | ノード | 内容 |
| --- | --- | --- |
| 雑談 | `warmup` | バイクをこぎながら、通い始めたきっかけを聞かれる。高瀬が独立した理由も出る |
| 癖の読み取り | `habit` | 姿勢から癖を言い当てられ、由衣が安心する。BPM は下がり、`cross` は上がる |
| 壁際ストレッチ | `stretch` | 壁と高瀬に挟まれる近さ。ここで BPM が 120 を超えると脈返しが開く |
| 営業トーク | `sales` | 回数券の話に由衣が「営業トークですよね」と返し、高瀬が一瞬弾かれる。謝れば修復できる |
| 作業後のお茶 | `tea` | ほうじ茶を飲みながらの雑談。会社の話をする、最終枠を空けている理由を聞く、黙って湯気を見る |
| 帰り際の雨 | `rain` | 霧雨が本降りになる。傘を借りる、止むまでいる、走って帰る（高瀬が濡れたままは帰さないと止める） |
| うなじ | `bedNeck` | 触る前に聞き、掌は数センチ手前で止まる。断れば語尾と同時に手が離れる |

- 癖の読み取り・営業トーク・雨の選択は、最後の裏カルテに追記として出ます（終わりの種類には関わりません）。
- 3つの場面すべてで距離を置いて帰ると、壁が積み上がって「空いた枠」になります。
- 意地で始めた夜でも、掌を返して雑談・ストレッチで逃げなければ、脈返しが開きます。手首を抜いた夜には開きません。
- `node js/simulate.js` で全ルートの到達と、各場面の文面を確認できます。

## 長編版で足した場面（2回目の夜）

`invite`（帰り支度）の前に、3つの場面を足しました。どれも越える・越えないの判定は変えず、数値の動きも小さくしてあります。

| 場面 | 内容 | 選択肢 |
|---|---|---|
| `talk` | トレーニング中の会話。来続けている理由・空けた理由が、前回の終わりごとに変わる | `s2_t_open`（話す）/ `s2_t_light`（愚痴だけ）/ `s2_t_deflect`（流す。高瀬は聞かず、手が半歩遠くなる） |
| `habit2` | 話すとき右肩が上がる癖を、高瀬に言い当てられる。責められず、安心する | `s2_h_trust` / `s2_h_laugh` / `s2_h_hide` |
| `tea2` | 施術のあとのお茶。脈を返したあとは、その余韻の一言が入る | `s2_tea_work` / `s2_tea_ask` |

`node js/simulate.js` の基準ルートは、`s2_t_light` → `s2_h_laugh` → `s2_tea_work` を通ります。
